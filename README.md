**MeowMetrics** translates your cat's midnight meows into a quarterly
business review — KPIs, a slide deck and an action plan for the tuna
division. One sentence, 157 chars, tournament winner 7-0; see `DESIGN.md`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt — the pitch, 157 bytes, no trailing newline
```
